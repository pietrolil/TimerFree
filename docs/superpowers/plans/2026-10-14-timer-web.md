# Timer Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um timer de circuito utilizável no Safari do iPhone, publicado como um único arquivo HTML estático, com avisos sonoros, pausa segura e tela acesa durante o treino.

**Architecture:** Código-fonte pequeno e separado por responsabilidade para facilitar testes; um script de build junta CSS e JavaScript em `index.html`, o único arquivo publicado. O modelo de fases e o relógio são funções sem DOM; a camada de navegador cuida de interface, som, armazenamento e Screen Wake Lock.

**Tech Stack:** HTML, CSS, JavaScript moderno, APIs Web nativas, Node.js 25 já disponível neste workspace, `node:test` e `esbuild` somente como dependência de desenvolvimento. Nenhuma dependência executada no navegador.

**Spec:** `docs/superpowers/specs/2026-10-14-timer-web-design.md`

## Global Constraints

- O artefato publicado é um único `index.html` com CSS e JavaScript embutidos, servido por HTTPS.
- Não criar servidor de aplicação, API, conta, banco de dados, analytics, APK ou dependência de rede durante o treino.
- Duração do exercício: 00:01 a 99:59. Transição e descanso: 00:00 a 99:59. Exercícios e sets: inteiros de 1 a 99.
- Transição ocorre só entre exercícios; descanso só entre sets; ambos com valor zero são omitidos. O primeiro exercício começa ao tocar em **Iniciar**.
- A página oculta pausa o treino; a retomada é manual. O treino ativo não precisa sobreviver a recarregamento.
- Última configuração salva apenas no navegador; falhas de armazenamento, áudio e Wake Lock não impedem a contagem.
- Safari no iPhone real é o alvo de validação de áudio, Wake Lock e ciclo de visibilidade. Simulação de iPhone não confirma esses comportamentos.

## Review Focus

1. Configuração guardada como JSON inválido ou fora da faixa deve recuperar valores iniciais válidos, sem tela quebrada. Cobrir na Task 3.
2. Toques repetidos em Iniciar, Pausar ou Continuar não devem criar múltiplos relógios nem avisos duplicados. Cobrir nas Tasks 2 e 4.
3. Um callback atrasado que atravessa várias fases deve mostrar a fase correta ou o fim, sem acumular atraso nem tocar uma rajada de avisos antigos. Cobrir na Task 2.
4. A página escondida perto do fim de uma fase deve congelar o estado e exigir retomada manual. Cobrir nas Tasks 2 e 5.
5. Tempos zero em transição e descanso devem levar diretamente à próxima fase, sem tela de 00:00 ou loop. Cobrir nas Tasks 1 e 4.

```js
export const DEFAULT_CONFIG = Object.freeze({
  exerciseSeconds: 30, transitionSeconds: 15, restSeconds: 60,
  exerciseCount: 4, setCount: 3
});
const limits = {
  exerciseSeconds: [1, 5999], transitionSeconds: [0, 5999], restSeconds: [0, 5999],
  exerciseCount: [1, 99], setCount: [1, 99]
};
export function validateConfig(raw) {
  const value = {}, errors = {};
  for (const [key, [min, max]] of Object.entries(limits)) {
    const input = raw?.[key];
    const number = typeof input === 'number' ? input :
      typeof input === 'string' && /^\d+$/.test(input.trim()) ? Number(input.trim()) : NaN;
    if (!Number.isInteger(number) || number < min || number > max)
      errors[key] = `Use um valor inteiro de ${min} a ${max}.`;
    else value[key] = number;
  }
  return { value: Object.keys(errors).length ? null : value, errors };
}
export function plannedSeconds(c) {
  return c.setCount * (c.exerciseCount * c.exerciseSeconds +
    (c.exerciseCount - 1) * c.transitionSeconds) + (c.setCount - 1) * c.restSeconds;
}
export function formatSeconds(total) {
  return `${String(Math.floor(total / 60)).padStart(2, '0')}:${String(total % 60).padStart(2, '0')}`;
}
export function buildPhases(c) {
  const phases = [];
  for (let set = 1; set <= c.setCount; set++) {
    for (let exercise = 1; exercise <= c.exerciseCount; exercise++) {
      phases.push({ kind: 'exercise', seconds: c.exerciseSeconds, set, exercise });
      if (exercise < c.exerciseCount && c.transitionSeconds > 0)
        phases.push({ kind: 'transition', seconds: c.transitionSeconds, set, nextExercise: exercise + 1 });
    }
    if (set < c.setCount && c.restSeconds > 0)
      phases.push({ kind: 'rest', seconds: c.restSeconds, set, nextSet: set + 1 });
  }
  return phases;
}
```

### Task 2: Relógio com pausa e avanço correto

**Files:** Create `src/timer-engine.mjs`, `tests/timer-engine.test.mjs`.

**Interfaces:**
- Consumes `Phase[]` from Task 1, each `seconds > 0`.
- Produces `new TimerEngine(phases)` with `start(nowMs)`, `tick(nowMs)`, `pause(nowMs)`, `resume(nowMs)`, `stop()` and `snapshot(nowMs)`.
- `start` and `tick` return `{ state, cue }`; `cue` is `'phase'`, `'complete'` or `null`. `state` is `{ status, phaseIndex, remainingMs }`, status in `idle|running|paused|complete`. `pause`, `resume`, `stop` return state. Calling methods redundantly has no effect.

- [ ] **Step 3: Implement a deadline-based engine.** On each tick, advance through elapsed deadlines in a loop; emit only the current phase cue or completion cue, never one cue per skipped phase. Pause stores remaining milliseconds, and resume sets a new deadline from `nowMs`.

```js
// Core transition in tick(nowMs):
while (this.status === 'running' && nowMs >= this.deadlineMs) {
  this.phaseIndex++;
  if (this.phaseIndex === this.phases.length) {
    this.status = 'complete';
    return { state: this.snapshot(nowMs), cue: 'complete' };
  }
  this.deadlineMs += this.phases[this.phaseIndex].seconds * 1000;
  entered = true;
}
return { state: this.snapshot(nowMs), cue: entered ? 'phase' : null };
```

export function loadConfig(storage) {
  try {
    const saved = JSON.parse(storage.getItem('timerfree.config.v1'));
    const result = validateConfig(saved);
    return Object.keys(result.errors).length ? DEFAULT_CONFIG : result.value;
  } catch { return DEFAULT_CONFIG; }
}
export function saveConfig(storage, config) {
  try { storage.setItem('timerfree.config.v1', JSON.stringify(config)); return true; }
  catch { return false; }
}
function readDuration(minutesInput, secondsInput) {
  const minutes = Number(minutesInput.value), seconds = Number(secondsInput.value);
  if (!/^\d+$/.test(minutesInput.value) || !/^\d+$/.test(secondsInput.value) ||
      !Number.isInteger(minutes) || minutes < 0 || minutes > 99 ||
      !Number.isInteger(seconds) || seconds < 0 || seconds > 59) return NaN;
  return minutes * 60 + seconds;
}
